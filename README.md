# Isometric Cover Builder (Конструктор изометрических обложек)

> Интерактивный веб-сервис для автоматической и ручной сборки брендированных изометрических 2D-обложек из векторных SVG-компонентов.

## 🌟 Возможности

- **🤖 Генерация по метафоре (AI Scenario):**
  - Преобразование заголовка статьи или абстрактной мысли в сбалансированную изометрическую композицию.
  - Автоматический подбор доминирующего объекта (Hero L), поддерживающего окружения (S) и оптимальной цветовой схемы.
  - Встроенный автономный эвристический генератор композиций.
- **🎨 Ручное конструирование (Manual Studio):**
  - Удобный каталог готовых векторных элементов (размеры L и S).
  - Drag-and-drop перетаскивание объектов на холст с плавной привязкой к изометрической сетке (30°).
  - Управление слоями (z-index), пропорциональное масштабирование, вращение и удаление.
- **🌈 Мгновенная адаптация палитры:**
  - 3 гармоничные темы: **Purple** (Неоновый фиолетовый), **Peach / Orange** (Тёплый коралл и персик), **Cyan / Mint** (Мятный циан).
  - Токенизированное динамическое перекрашивание всех SVG-элементов на лету без потери качества.
- **📐 3 стандартных формата:**
  - Квадрат `1080x1080` (посты, соцсети);
  - Горизонтальный `1920x1080` (статьи, блоги, презентации);
  - Вертикальный `1080x1920` (Stories, Reels, мобайл).
- **💾 Экспорт результата:**
  - Экспорт в чистый векторный SVG (минимальный вес, бесконечная резкость);
  - Экспорт в PNG 2x для мгновенной публикации в медиа.

## 🛠 Технологический стек

- **Фреймворк:** React 19 + Vite 6
- **Язык:** TypeScript 5
- **Стилизация:** Tailwind CSS 4
- **Управление состоянием:** Zustand
- **Иконки:** Lucide React
- **Графический движок:** Native SVG DOM с изометрическими матричными преобразованиями

## 🚀 Быстрый старт

### Требования
- Node.js >= 18.18.0
- npm / pnpm / yarn

### Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/pradigmaz/isometric-cover-builder.git
cd isometric-cover-builder

# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev
```

Локальный сервер запустится по адресу: `http://localhost:5173`.

### Сборка для продакшена

```bash
npm run build
npm run preview
```

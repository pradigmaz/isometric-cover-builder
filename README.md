# Isometric Cover Builder (Конструктор изометрических обложек)

> Интерактивный веб-сервис и плагин для Figma для автоматической и ручной сборки брендированных изометрических 2D-обложек из чистых векторных SVG-компонентов.

- **Живой сервис (Веб-студия):** https://isometric-cover-builder.vercel.app/
- **Режим превью Figma-плагина:** https://isometric-cover-builder.vercel.app/?plugin=true

## 🌟 Возможности сервиса и плагина Figma

- **🤖 Сценарий 1: Генерация по метафоре или заголовку**
  - Пользователь вводит тему статьи или заголовок (например, *«Финтех и безопасность»*, *«UX дизайн»*, *«Креатив и стратегия»*).
  - Алгоритм анализирует семантические токены и выстраивает гармоничную изометрическую композицию из библиотеки исходных векторных объектов без использования растровых нейросетей.
  - Поддерживается автоматическое разделение на роли: главный объект на столе (`hero`), предметы окружения (`satellite`) и фоновый силуэт на стене (`ghost`).

- **🧩 Сценарий 2: Сборка по списку компонентов**
  - Пользователь выбирает или вводит названия нужных предметов (*«книга, пазлы, ручка, телефон»*).
  - Умный геометрический компоновщик (`src/engine/smartComposer.ts`) рассчитывает координаты вдоль 30° изометрической сетки в 5 пространственных архетипах с защитой от нагромождения (минимальная дистанция `160–220 px` в зависимости от формата) и сохранением единого масштаба без искажения относительных пропорций объектов.

- **🔌 Нативный плагин для Figma**
  - Полнофункциональный интерфейс прямо в Figma (готовые пресеты, умный генератор, случайная композиция, переключение форматов и тем).
  - Экспорт в нативные векторные ноды Figma (`figma.createNodeFromSvg`): векторные слои сохраняются как редактируемые кривые с именованием (`[Item] Smartphone L`, `[Table] Base`).
  - Каталог отдельных векторных компонентов (L и S) для мгновенной вставки в рабочий макет.

- **🎨 Палитры Студии «Очень» и токенизация**
  - 3 канонические темы:
    - **Лаванда** (`lavender`)
    - **Персик и мята** (`peach-mint`)
    - **Бирюза и сирень** (`turquoise-purple`)
  - Поддерживается также загрузка и переключение пользовательских цветовых палитр.
  - Векторная графика построена на семантических CSS-переменных (`var(--token-primary)`, `var(--token-secondary)`, `var(--token-accent)`), что гарантирует мгновенное переключение цветов без изменения исходных контуров.

- **📐 4 формата обложек**
  - **1200×630** (Обложка статьи / OG image для соцсетей);
  - **1920×1080** (Горизонтальный 16:9 для презентаций и видео);
  - **1080×1080** (Квадрат 1:1 для постов);
  - **1080×1920** (Вертикальный 9:16 для Stories и мобайла).

- **📐 3 варианта компоновки**
  - **По центру** (собранная плотная группа в оптическом фокусе);
  - **Диагональ** (динамическое смещение вдоль 30° изометрической оси);
  - **Свободное поле** (смещение композиции вправо для свободного размещения крупного заголовка слева).

## 🏛 Архитектура: хранение, извлечение и переиспользование SVG

### 1. Хранение компонентов
Векторные иллюстрации хранятся в виде типизированного каталога контурных примитивов в коде (`src/assets/primitives.tsx` и `src/assets/registry.ts`).
- Каждый компонент описан через чистые векторные пути `<path>`, `<polygon>`, `<g>`, полученные из 20 исходных эталонных работ Студии «Очень».
- Объекты не содержат захардкоженных hex-цветов: все заливки (`fill`) и обводки (`stroke`) ссылаются на CSS-токены темы (`var(--token-*)`).
- В библиотеке зарегистрированы 10 ключевых предметов в размерах `L` (600×600) и `S` (200×200):
  - *Базовые поверхности:* Книга / Блокнот (`notepad`), Папка (`folder`);
  - *Гаджеты и хранение:* Смартфон (`smartphone`), Наушники (`headphones`), Кошелёк (`wallet`);
  - *Детали и символы:* Монета (`coin`), Ручка (`pen`), Пазлы (`puzzle`);
  - *Фоновые элементы:* Лампа (`lamp`), Ваза с цветами (`flowers_vase`).

### 2. Извлечение и параметризация
При запросе на генерацию или ручном добавлении:
- Парсер ключевых слов (`src/engine/componentKeywords.ts`, `src/engine/generator.ts`) распознаёт русские и английские синонимы, падежи, частые опечатки и размерные модификаторы («большая книга», «мелкая монета»).
- Резолвер сопоставляет запрос с эталонными шаблонами композиций (при `seed = 0` / без сида) либо передаёт набор в иерархический геометрический компоновщик (`src/engine/smartComposer.ts`) с рандомизацией по `seed` (ротация палитр, архетипов, ролей `foreground`/`ghost` и размеров `L`/`S`).
- Экземпляры объектов параметризуются матрицей трансформации: координаты $(x, y)$, единый масштаб формата (`UNIFORM_SCALE_BY_FORMAT`), роль (`foreground` / `ghost`) и z-порядок слоя (`manualLayerOffset`).

### 3. Переиспользование и изометрическая сборка
- Компоненты переиспользуются по принципу конструктора без искажения исходных пропорций (согласно правилам композиции ТЗ).
- Сборка на холсте (`src/components/canvas/IsometricCanvas.tsx`):
  1. **Фоновый слой (Стена / Силуэты):** изометрическая плоскость стены и фоновые объекты (`role: 'ghost'`), отрисованные плотным монохромом активной палитры без чёрного контура (с возможностью журнального выхода до 25% за край артборда);
  2. **Слой стола:** изометрическая плоскость столешницы (угол наклона 30°);
  3. **Слой основных объектов:** векторные группы с расчётом изометрической глубины;
  4. **Слой деталей:** аксессуары первого плана.
- При экспорте в SVG (`src/engine/exporter.ts` для веб-студии и `src/plugin/svgHelper.ts` для Figma-плагина) CSS-переменные инлайнятся в конкретные hex-значения выбранной темы, обеспечивая 100% совместимость с Figma и любыми внешними векторными редакторами.

## 🤖 Использованные AI-инструменты при разработке

1. **Google Antigravity (Gemini):**
   - Архитектурное проектирование сервиса и плагина Figma;
   - Математическое моделирование изометрической проекции (30°) и расчёт непересекающихся BBox-координат;
   - Реализация семантического анализатора метафор и парсера естественного языка;
   - Автоматизированное тестирование (`npx tsx --test`, 168 автотестов) и непрерывный Fresh Eye код-аудит качества.
2. **Figma Plugin API & Typings:**
   - Генерация нативных векторных узлов через `createNodeFromSvg` с сохранением древовидной структуры слоёв.

## 🖼 Примеры сгенерированных композиций

1. **«Финтех и венчурные инвестиции» (Лампа + Кошелёк + Монета)**
   - *Формат:* 1200×630 (OG)
   - *Палитра:* Персик и мята (`peach-mint`)
   - *Роли:* Лампа — монохромный фоновый объект на стене (`ghost`); Кошелёк — главный объект на столе (`hero`, `L`); Монета — акцент переднего плана (`S`).
2. **«UX-дизайн и стратегия» (Книга + Пазлы + Ручка + Телефон)**
   - *Формат:* 1200×630 (OG)
   - *Палитра:* Лаванда (`lavender`)
   - *Роли:* Открытая книга — база на столе; Пазл (`S`) — элемент на развороте; Смартфон — рядом на поверхности стола вдоль 30° оси; Ручка (`S`) — на переднем плане.
3. **«Музыка и подкасты» (Наушники + Ваза с цветами)**
   - *Формат:* 1080×1080 (1:1)
   - *Палитра:* Бирюза и сирень (`turquoise-purple`)
   - *Роли:* Крупные наушники в фокусе (доминанта кадра, `L`); Ваза с цветами — монохромный фоновый объект на заднем плане (`ghost`).

## 🚀 Запуск проекта и установка плагина

### 1. Веб-сервис

```bash
# Установка зависимостей
npm install

# Запуск локального сервера (порт 5173)
npm run dev

# Запуск тестов
npm test

# Сборка проекта
npm run build
```

Сервис доступен по адресу: `http://localhost:5173` (веб-студия) и `http://localhost:5173/?plugin=true` (веб-версия плагина).

### 2. Установка плагина в Figma Desktop

1. В Figma откройте меню: **Plugins** → **Development** → **Import plugin from manifest...**
2. Выберите файл `manifest.json` в корне репозитория (или в распакованном `public/isometric-cover-builder-plugin.zip`).
3. Плагин **Isometric Cover Builder** готов к работе!
